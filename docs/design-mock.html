DESIGN SPEC v2 (モック専用欄)

Concept
アイコンの手描き線画の世界観をそのままUIに拡張。ゆらいだ角丸・傾いたスタンプ・タピオカの粒・吹き出し・マーカー線で「手描きの遊び」を足しつつ、本文の読みやすさは崩さない。
v1からの変更
明朝→丸ゴシック見出し / 直線罫→破線+ゆらぎ角丸 / Highlights廃止(実績はCareerに統合+スタンプ化) / リンクをアイコン付きボタンに / マーキー・タピオカ・吹き出し追加。
Palette
紙白 / 墨 / 淡墨 / 朱 (or 藍・松)。v1から据え置き。
Typography
見出し: 丸ゴシック太字 (Hiragino Maru Gothic)。本文: ゴシック。日付・技術: 等幅。システムフォントのみ。
Motion
タピオカの浮遊 / マーキー / ホバーで傾く程度に抑制。prefers-reduced-motion で全停止。
