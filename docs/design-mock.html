DESIGN SPEC (モック専用欄)

Concept
アイコンの白黒線画を基準にした「紙と墨」。アクセントは印鑑の朱を署名的に少量だけ使う (見出しラベル・タイムラインの点・フッターの印)。
Palette
紙白 / 墨 / 淡墨 / 朱 (or 藍・松)。ダークは墨紙に反転。
Typography
見出し: 明朝 (Hiragino Mincho / Yu Mincho)。本文: ゴシック。日付・URL・技術タグ: 等幅。すべてシステムフォントで Web フォント読み込みなし。
Layout
1カラム左寄せ、本文幅は40rem上限。カードは角丸2px・細罫線のみ。装飾アニメーションなし、ホバーで罫線が朱になる程度。
実装時に決めること
・ヒーローコピー確定 (現在は仮置き)
・アイコン画像の配置 (assets/icon.png)
・iegoto スクリーンショットの選定
・アクセント色の確定 (右上の切り替えで比較)
