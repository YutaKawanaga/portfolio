# ポートフォリオサイト 企画書

作成日: 2026-07-23
ステータス: 企画中 (実装未着手)

## 1. 目的とターゲット

- **主目的**: 転職活動。応募フォームの「ポートフォリオURL」欄に貼れる、職務経歴の Web 版ハブ
- **読者の二段構え**:
  1. 採用担当 (非エンジニア): 30秒で「何ができる人か」が伝わること
  2. エンジニア面接官: 実績の深掘り (技術選定・設計判断・成果) に耐えること
- **言語**: 日本語のみ

## 2. 打ち出すメッセージ (職務経歴書から抽出)

差別化になる強みは次の3点。サイト全体をこの3点に収束させる。

1. **AIネイティブな開発組織づくり** — レビュー・リリース・障害対応・採用補助を
   AIエージェント前提のフローへ再構築した実績 (2025〜)。市場にまだ少ない経験で、一番の売り
2. **横断力** — フロント / バックエンド / インフラ (AWS・GCP両方) / ブラウザ拡張まで自ら実装。
   0→1 (1人目エンジニア) も、稼働中プロダクトの無停止フルリプレースも経験
3. **チームの生産性への視点** — 採用・マネジメント・仕組みづくり・AI-DLCカンバン導入。
   個人の生産性ではなく組織の生産性を上げてきた

ヒーローコピー案 (要選定):

- 「プロダクトと組織を、エンジニアリングで前に進める」
- 「実装から組織づくりまで。AI前提の開発をつくるエンジニア」
- 「フロントからインフラ、そしてチームまで、横断して手を動かす」

## 3. サイト構成 (1ページ構成を推奨)

転職用途では回遊よりも「上から読めば全部わかる」ことが重要なため、
セクションアンカー付きの1ページ構成とする。

| # | セクション | 内容 |
|---|---|---|
| 1 | Hero | 名前・肩書き・コピー・アイコン・各種リンク |
| 2 | Highlights | 選抜3実績をカードで: ①開発組織のAIネイティブ化 ②プロダクト全面リプレース (AWS→GCP / Django→Kotlin) ③1人目エンジニアとしての SaaS 0→1 |
| 3 | 職務経歴 | 4社をタイムライン形式で。各社は概要+主要プロジェクトの要約。詳細は `docs/content.md` |
| 4 | 個人開発 | iegoto のケーススタディ (課題→設計→0円運用構成→運用) |
| 5 | スキル | 実績に紐付けたグルーピング表示 (羅列にしない) |
| 6 | アウトプット | Zenn / Qiita / GitHub へのリンク+代表記事があればピックアップ |
| 7 | 連絡先 | メール・GitHub。問い合わせフォームは作らない |

補足: 職務経歴書 PDF そのものへのリンクは置かない (公開サイトに載せる粒度と
書類選考に出す粒度は分ける。§6 参照)。

## 4. デザイン方針

- ミニマル系: 白/黒基調 + アクセント1色、タイポグラフィ主体。装飾的アニメーションはしない
- ダークモード対応・レスポンシブ必須
- 採用担当が読む前提で、本文の可読性 (行間・文字サイズ・コントラスト) を最優先
- アイコン画像は**未決** (§7)

## 5. 技術構成 (推奨案)

- **推奨: Astro + Tailwind CSS**
  - ほぼ静的コンテンツの日本語サイトであり、SSG が適材。ビルド成果物が軽く Lighthouse も出しやすい
  - 「新しい技術を1つ試した」という話題性も面接で使える
- 代替: Vite + React (iegoto と同スタック。学習コストゼロだが静的サイトにはオーバースペック)
- ホスティング: **Vercel Hobby** (iegoto と同アカウント。帯域等の無料枠はアカウント共有だが
  静的サイトのため影響は無視できる)
- URL: 当面 `*.vercel.app` サブドメインで公開。カスタムドメインは後からいつでも
  無停止で追加できるため、取得判断は公開後に持ち越して良い (Vercel 側の追加費用はゼロ、
  レジストラへの登録料 年1,000〜2,000円程度のみ)

## 6. 公開にあたっての注意

- **リポジトリ/サイトは全世界公開前提**で書く。職務経歴書にある社内数値
  (工数削減率、業務委託人数など) は、サイト掲載時は表現を丸めるか掲載可否を判断する
- **アイコンの権利問題**: 現在 Zenn で使用中のぽちゃっこ (サンリオキャラクター) の
  手描きイラストは、描き手が家族でも二次創作でありサンリオの著作権が及ぶ。
  転職用の対外サイトでの使用は避け、オリジナルイラストへの差し替えを推奨 (§7)
- シークレット・個人の住所/電話番号は一切コミットしない
