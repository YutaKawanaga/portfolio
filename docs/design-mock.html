DESIGN SPEC v3 (モック専用欄)

Concept
「柔らかいけど落ち着いてる」。丸ゴシック見出し・ピル形状・控えめなマーカー強調で温度を残しつつ、傾き・ゆらぎ・装飾アニメーションは使わない。
v2からの変更
タピオカ・吹き出し・マーキー・ゆらぎ角丸・要素の傾き・オフセット影を撤去。チップは傾いたスタンプ→静かなピルに。動きはホバー時の浮き上がりのみ。
Palette
紙白 / 墨 / 淡墨 / 朱 (or 藍・松)。据え置き。
Typography
見出し: 丸ゴシック太字。本文: ゴシック。日付・技術: 等幅。システムフォントのみ。
残した遊び
マーカー強調 (hero/about) / ピル型チップ / フッターのわずかに傾いた印鑑 / ホバーの浮き上がり。
