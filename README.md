# portfolio

川永勇多の個人ポートフォリオサイト。転職活動時に「ポートフォリオURL」として提示できる、職務経歴の Web 版ハブ。

現在は企画フェーズ。実装前の意思決定は `docs/` に記録する。

- `docs/plan.md` — 企画書 (目的・サイト構成・デザイン方針・技術構成・未決事項)
- `docs/content.md` — 掲載コンテンツの下書き (職務経歴書を Web 掲載用に再構成したもの)

## 予定している構成

- Astro + Tailwind CSS (推奨案。確定は plan.md §7 参照)
- Vercel Hobby でホスティング (当面は `*.vercel.app`、カスタムドメインは公開後に判断)
